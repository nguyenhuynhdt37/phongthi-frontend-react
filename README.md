# 🏛️ Smart Exam Room Admin Dashboard - Quản Lý Phòng Thi Thông Minh

Web Admin Dashboard giám sát và quản lý **Hệ Thống Phòng Thi Thông Minh**. Xây dựng dựa trên template TailAdmin Next.js chuyên nghiệp với 390+ mã nguồn linh hoạt.

---

## ✨ Tính Năng Nổi Bật

- 📋 **Quản Lý Lịch Thi & Phòng Thi:** Xếp lịch thi, phân công giám thị, số lượng thí sinh.
- 📊 **Giám Sát Thời Gian Thực:** Bảng điều khiển theo dõi trạng thái phòng thi, thí sinh điểm danh.
- 📄 **Xuất Báo Cáo:** Xuất danh sách phòng thi và kết quả thi ra Excel/PDF.

```bash
git clone https://github.com/nguyenhuynhdt37/phongthi-frontend-react.git
cd phongthi-frontend-react
npm install
npm run dev
```
